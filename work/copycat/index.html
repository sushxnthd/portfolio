CopyCAT

An exact finite-archive audit of how duplicating existing benchmark roots can change a winner without changing any model outputs.

Source repository ↗
Status
Public manuscript and executable evidence
Scope
588 aligned English questions; 10 released configurations
Intervention
One extra copy per root; shared schedule across systems
Boundary
Not a measure of naturally occurring semantic duplication

Question

A benchmark score is not only a function of model behavior; it also depends on how evaluation units are weighted. CopyCAT asks which decisions remain possible when existing roots may be counted twice under a bounded shared copy schedule.

Result

532/588baseline winner score
3minimum copies for one challenger
8minimum copies for another challenger
7configurations excluded by certificates

The released archive identifies Gemini-3.8-Flash as the baseline winner, GPT-6.1-Sol and Claude-Sonnet-5.5 as challengers. The result concerns this pinned archive, not population-level model superiority.

Reproduce

The compact lossless binary matrix and supplied winner certificates are checked using only the Python standard library; no model inference or paid API is required.

python code/reproduce_headline.py

The stored regression report records 680 joint-winner problems checked against independent brute force and a 51-check consistency audit.
