QUESTION / 002

Can a counterexample tell you what to learn next?

My first version could recover some hidden algebraic operations from a small number of queries. On frozen public holdouts, it missed 48 eligible cases, all involving nonassociative loops.

That failure exposed the missing move: instead of only rejecting a bad reconstruction, query the translation that falsified it. Add that structure. Try again.

The corrected v1.2 reached 345/345 eligible cases on this defined algebra benchmark. That's a narrow result, not a claim that it can autonomously discover general scientific laws.

CASE FILE 003HUMAN SENSING / ANDROID2025—26

Somno

A working app, not a Figma file. I wanted the whole thing to run on a phone.

QUESTION / 003

What if your phone could help you notice when you're too tired to focus?

Somno combines reaction-time testing, subjective sleepiness, facial/ocular signals processed on-device, and recent sleep history to estimate fatigue relative to your own baseline.

It's a real Android release. I built the app, modeled the scoring and recovery logic, and shipped a package that can be installed.

PLATFORMAndroid
INPUTS4 signal families
RELEASEv27 / public

Not a medical device. The app does not diagnose conditions or infer sleep stages from face video. The output is an awareness estimate.
