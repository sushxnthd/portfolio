05 / HOW I WORK

Operating principles.

01

Start from the bottleneck.

A polished interface around the wrong problem is still the wrong problem.

02

Make claims expensive.

If a claim matters, it should survive stronger baselines, adversarial tests, and reproduction.

03

Use AI as leverage, not theater.

The point is to compress iteration cycles and attempt work that would otherwise be inaccessible.

04

Build in public evidence.

Repos, demos, experiments, failed branches, measurements. Output should be inspectable.
